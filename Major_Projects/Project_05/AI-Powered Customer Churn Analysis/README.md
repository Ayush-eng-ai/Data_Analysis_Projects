# AI-Powered Customer Churn Analysis

## 📌 Project Overview

Customer churn is one of the biggest challenges for subscription-based businesses. This project analyzes customer behavior and identifies key factors that influence customer churn using SQL, Python, Excel, and Tableau.

The project combines exploratory data analysis, machine learning, and interactive dashboarding to generate business insights that can help improve customer retention.

---

## 🎯 Business Problem

Telecommunication companies lose revenue when customers leave their services. Understanding why customers churn helps businesses:

* Improve customer retention
* Reduce revenue loss
* Identify high-risk customer groups
* Create targeted retention strategies

## 🔍 Key Insights

* Month-to-month customers show the highest churn.
* Fiber optic users have higher churn behavior.
* Electronic check customers are more likely to leave.
* Customers with shorter tenure are at higher risk of churn.
